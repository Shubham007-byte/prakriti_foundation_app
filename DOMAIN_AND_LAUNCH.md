# Domain and launch checklist

Preferred domain: `prakritishaktifoundation.org`

- [ ] Search the exact domain at a registrar (availability was not confirmed by this starter build).
- [ ] Register it in an account controlled by the foundation, enable auto-renew and MFA, and store recovery details securely.
- [ ] Deploy the Next.js app and add the domain in the host's dashboard.
- [ ] Copy the host-provided DNS records exactly; do not guess A/CNAME values.
- [ ] Confirm HTTPS certificate and redirect the non-canonical hostname to the canonical one.
- [ ] Configure Supabase Auth site URL and allowed redirect URLs for the production hostname.
- [ ] Replace all draft text and sample imagery with foundation-approved content and consented photos.
- [ ] Verify official contact details and payment recipient before publishing any donation QR/UPI details.
- [ ] Test access using one admin and one non-admin account; confirm non-admin writes are denied by RLS.
- [ ] Review privacy notice, photo consent, data retention, backup/restore and relevant legal/compliance obligations before launch.
